Cómo crea las variantes el motor

Esta página calcula el plan en vivo y enseña el encuadre real de cada pantalla, pero no transcodifica: eso lo hace el motor, con ffmpeg, y su veredicto se carga aquí desde signage/bateria-informe.json cuando existe. El motor no se fía de que ffmpeg devuelva 0: vuelve a leer cada fichero de salida con ffprobe y compara con lo que se pidió.

node scripts/signage-bateria.mjs mi-campana.mp4 --limpiar

Sale un fichero por pantalla en signage/variantes/ y el informe con el veredicto. El proceso solo termina en error si alguna pantalla falla; «ajustada» es información, no error — una barra estirada siempre saldrá ajustada.
